# 飞书日志与周报模板

## 每日实验日志

标题：`YYYY-MM-DD 实验日志-<姓名>`，例如 `2026-11-17 实验日志-李振辉`。

```markdown
# 今日进展
- 做了什么（实验/分析），关键结果和数字。
- 只记当天的科研/实验进展。

# 存在问题
- 遇到的问题，不确定的直说。

# 后续计划
- 下一步动作本身（做什么，不写“要先和谁商定”这种安排）。

# 实验条件（有实验才写）
- 试剂批次：
- 仪器型号：
- 实验条件：
- 原始数据：
```

写作要求：短，只留 headline 结果和一两个关键数字；原因就是故事本身时原因先给；文书活、订阅与工具类行政事项不进日报。

## 组会周报

标题：`组会周报-<姓名>`，例如 `组会周报-李振辉`。

```markdown
# 本周进展
- 结论先给，数字后面补“为什么”。

# 存在问题
- 卡在哪里，需要谁配合。

# 下周计划
- 具体动作和时间点。
```
