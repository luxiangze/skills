# 使用注意事项

这些约定是为了让几个人共用的小集群还能跑起来。提交前先用 `sinfo` 和 `df` 看当前状态，不要把下面的日期数字当成永远不变。

- 登录节点只做编辑、提交和查看。训练、大规模解压、长时间编译都提交到计算节点。
- 作业脚本、输入和需要保留的输出放在共享存储上。只存在于登录节点本地家目录的路径，计算节点访问不到，作业会报 `couldn't chdir`。
- 家目录权限通常是 `0700`。要和别人共享数据时，单独建一个双方都同意的目录并设置组权限，不要改别人的家目录权限。
- `/share` 是 NFS。2026-10-11 时大约用了 81%。大的中间文件用完就删，避免产生海量小文件。提交前执行 `df -h /share`。
- 节点本地 `/tmp` 不共享，也不备份。大的临时文件可以写到那里，作业结束时必须删除。2026-10-11 时计算节点 `/tmp` 大约 98G，以作业里的 `df -h /tmp` 为准。
- 分区没有最长运行时间限制，但仍要写 `--time`。长时间作业要能从检查点继续，不要假设一次能跑完。
- array 用 `%N` 限制同时运行的任务数，例如 `--array=1-100%8`。
- 只取消自己的作业。取消前用 `squeue -u "$USER"` 确认作业号。
- 多于 1 块 GPU、array 并发很大、超过 32 核或 64G 内存时，先问用户再提交。
