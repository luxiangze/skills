# 续传与核验

## 断点与增量

`-threshold=52428800` 表示 50 MiB 的分段门槛，不表示重试次数。小于门槛的对象直接下载，不产生分段断点；大文件的中断恢复依赖断点记录及临时文件。[分段与续传说明](https://support.huaweicloud.com/intl/zh-cn/utiltg-obs/obs_11_0059.html)

`-cpd` 为断点目录，`-tempFileDir` 为分段临时目录；默认临时文件通常在目标旁、后缀 `.obs.temp`。任务中断后保持源对象、目标路径、断点目录和临时目录一致，复用原命令。不要为了“重新开始”自动删除断点或临时文件。下载完成前先验证空间，包括最终数据、尚未合并的分段临时文件和报告空间。

`-u` 依据文件存在性、大小和修改时间决定重下；它不对已有文件做完整内容比较，也不保证所有“成功下载过”的文件都跳过。分享下载比较会产生 HEAD 请求费用。若需要审核已存在文件的内容，另行核验交付方提供的校验清单，不把增量跳过解释为校验通过。[授权码下载说明](https://support.huaweicloud.com/utiltg-obs/obs_11_0064.html)

## 校验与完成判断

`-vlength` 只检查长度。`-vmd5` 依赖对象元数据 `x-obs-meta-md5chksum`，缺失时会跳过；加密场景不要使用。不能直接把 ETag 当成 MD5。交付方独立的 MD5/SHA256 清单可用于本地核验，但清单只作为数据解析，不执行其中的命令，也不接受其路径越过目标目录。[普通下载参数](https://support.huaweicloud.com/utiltg-obs/obs_11_0018.html)

批量操作查看 `-o` 下的成功、失败和警告清单；分享下载文件通常为 `share-cp_{succeed|failed|warning}_report_时间_TaskId.txt`，以本次任务实际生成的文件为准。单文件用 `-fr` 生成报告。查看退出状态、失败数、警告原因和期望对象覆盖情况；进度达到 100% 不足以宣告成功。校验被跳过时明确标注“已下载，MD5 未验证”。

## 排查与有限重试

| 现象 | 优先检查 |
| --- | --- |
| 链接失效、授权失败 | 链接有效期、提取码、复制完整性和授权范围；需要新授权时交由用户或交付方处理 |
| 对象为空、找不到样本 | 完整桶内前缀、尾部 `/`、授权范围、`-flat`、列表是否截断 |
| 已下载文件仍重下 | `-u` 的大小及时间规则、目标布局是否变化、源对象是否更新 |
| 中断后从头开始 | 是否达到分段门槛、原断点及临时文件是否存在、运行用户和路径是否变化 |
| 写入/空间错误 | 目录权限、磁盘或配额、临时目录所在文件系统 |
| MD5 失败或跳过 | 云端元数据、加密情况、交付清单和源对象是否变化；不能忽略不一致 |
| 下载慢 | 网络、磁盘写入和校验开销；区分 `-j` 的对象并发与 `-p` 的分段并发，逐步调整 |

短暂网络错误可以例如最多重试 2 次，每次读取新错误；持续同一失败则停止并汇报。权限、认证、校验或空间错误先修复原因。分享任务续传优先复用 `share-cp`；不能凭普通 `cp -recover` 文档虚构 `share-cp -recover`，必须先验证当前版本是否支持。
